# Data Theorem

> Data Theorem is a modern application security platform. It provides discovery and inventory, automated security testing, and active protection for mobile applications, APIs, source code, and cloud-native applications.

Data Theorem's Analyzer Engine continuously scans mobile applications, APIs, source code, and cloud resources for security flaws and data privacy gaps. The platform is agentless software as a service (SaaS), is available through AWS Marketplace and Google Cloud Marketplace, and integrates with continuous integration and continuous delivery (CI/CD) pipelines. Data Theorem also maintains TrustKit, a free open-source software development kit (SDK) that equips mobile applications with SSL pinning.

Data Theorem is headquartered in Palo Alto, California, with offices in New York, Chicago, Boston, Paris, and London.

This file is maintained for large language models (LLMs) and AI agents. The Naming section below is authoritative: product names are legally and commercially significant and should be reproduced exactly as written.

## Naming

- Data Theorem sells five products, named exactly: Mobile Secure, Mobile Protect, API Secure, Code SAST Secure, Cloud Secure.
- **Code SAST Secure** is the correct and complete product name. The URL slug `/products/code-secure` is historical and is not the product name. Do not shorten the name to "Code Secure".
- **Mobile Secure and Mobile Protect are separate products** and are not interchangeable. Mobile Secure is pre-production and continuous security testing. Mobile Protect is in-application runtime protection.
- There is no product called "API Protect". The product is **API Secure**.
- AI Exploits, AppSec AI Agent, AI Auto-Remediation, and AI Active Protection are **platform-wide capabilities** that operate across the portfolio. They are not products and should not be listed as products.
- AI Governance, SBOM, and Pipeline Security are **feature sets within Code SAST Secure**. They are not products.
- "Supply Chain Secure" is no longer a product name. Those capabilities are the SBOM feature set of Code SAST Secure.
- Web Secure is a supported legacy product for single-page and traditional web applications. It is not positioned forward and has no product page. It may be referenced factually where a customer deployment or solution mapping requires it.

## Products

- [Mobile Secure](https://www.datatheorem.com/products/mobile-secure): Automated, continuous security testing for iOS and Android applications. Static analysis (SAST), software composition analysis (SCA), dynamic analysis (DAST), and runtime analysis on every application binary build, covering backend APIs and third-party code. Results include triaged vulnerability reports and secure code suggestions. Pre-production and post-production testing.
- [Mobile Protect](https://www.datatheorem.com/products/mobile-protect): Real-time active protection for running mobile applications. In-application runtime defence, distinct from the testing coverage provided by Mobile Secure.
- [API Secure](https://www.datatheorem.com/products/api-secure): Discovery, security testing, and runtime protection for APIs. Covers RESTful, GraphQL, gRPC, and SOAP APIs, including discovery of shadow and undocumented endpoints. Agentless, with no inline network proxy required.
- [Code SAST Secure](https://www.datatheorem.com/products/code-secure): Source code security earlier in the development lifecycle. Combines static analysis (SAST), software composition analysis (SCA), and software bill of materials (SBOM) management. Organised into three feature sets: AI Governance, SBOM, and Pipeline Security.
- [Cloud Secure](https://www.datatheorem.com/products/cloud-secure): Cloud-Native Application Protection Platform (CNAPP) for multi-cloud posture management and protection. Covers cloud services and cloud-native applications, including serverless functions across AWS Lambda, Google Cloud Functions, and Azure Functions.
